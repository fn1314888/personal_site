Introduction

In Part 1, we treated synchronous Boolean networks as autonomous dynamical systems. The term autonomous means the update rule does not depend on external inputs or time. In Part 2, we will introduce inputs and outputs to synchronous Boolean networks to produce synchronous Boolean control networks, which are non-autonomous dynamical systems.1 Then we will wander off to automata theory and introduce finite state machines, Moore machines in particular. It may seem like a strange departure to start thinking about computation, for we have been looking at things from the perspective of dynamical systems up until now. But in the end, we will see that synchronous Boolean control networks and Moore machines have a very interesting relationship, which leads to an even more interesting idea.

1 The term control originated from the intention to control or intervene in the dynamics of the system to reach desired states. But that will not be our intention.

Synchronous Boolean Control Networks

A synchronous Boolean control network is a tuple \((V, U, Y, F, H)\), where the components are defined as follows:

  • \(V = \{v_1, v_2, \dots, v_n\}\) is a finite ordered set of \(n\) state variables, where each variable takes values in \(\{0, 1\}\). At time \(t \in \mathbb{N}_0\), the state vector is \(\mathbf{x}(t) = (x_1(t), x_2(t), \dots, x_n(t)) \in \{0, 1\}^n\).
  • \(U = \{u_1, u_2, \dots, u_m\}\) is a finite ordered set of \(m\) input variables, where each variable takes values in \(\{0, 1\}\). At time \(t \in \mathbb{N}_0\), the input vector is \(\mathbf{u}(t) = (u_1(t), u_2(t), \dots, u_m(t))\).
  • \(Y = \{y_1, y_2, \dots, y_p\}\) is a finite ordered set of \(p\) output variables, where each variable takes values in \(\{0, 1\}\). At time \(t \in \mathbb{N}_0\), the output vector is \(\mathbf{y}(t) = (y_1(t), y_2(t), \dots, y_p(t))\).
  • \(F: \{0, 1\}^n \times \{0, 1\}^m \rightarrow \{0, 1\}^n\) is the global state transition function, defined by: \[ F(\mathbf{x}(t), \mathbf{u}(t)) = (f_1(\mathbf{x}(t), \mathbf{u}(t)), f_2(\mathbf{x}(t), \mathbf{u}(t)), \dots, f_n(\mathbf{x}(t), \mathbf{u}(t))) \] where each local transition function \(f_i: \{0, 1\}^n \times \{0, 1\}^m \rightarrow \{0, 1\}^n\) determines the next state value \(x_i(t + 1)\) of variable \(v_i\).
  • \(H: \{0, 1\}^n \rightarrow \{0, 1\}^p\) is the global output function, defined by: \[ H(\mathbf{x}(t)) = (h_1(\mathbf{x}(t)), h_2(\mathbf{x}(t)), \dots, h_p(\mathbf{x}(t))) \] where each local output function \(h_j: \{0, 1\}^n \rightarrow \{0, 1\}\) determines the current value \(y_j(t)\) of variable \(y_j\).
NoteIn Plain English

A synchronous Boolean control network adds inputs and outputs to standard synchronous Boolean networks. It has five parts:

  • State Variables(\(V\)): These are \(n\) internal switches. Their values \(\mathbf{x}(t)\) describe the system’s internal state at time \(t\).
  • Input Variables(\(U\)): These are \(m\) external switches. Their values \(\mathbf{u}(t)\) are the inputs that influence how the internal state changes at time \(t\).
  • Output Variables(\(Y\)): These are \(p\) external switches. Their values \(\mathbf{y}(t)\) are the outputs at time \(t\).
  • Global Transition Function(\(F\)): This is the master update rule. To find the next state \(\mathbf{x}(t + 1)\), every internal switch applies its update rule \(f_i\) using both the current internal state \(\mathbf{x}(t)\) and the current external input \(\mathbf{u}(t)\).
  • Global Output Function(\(H\)): This is the output rule. To get the current output \(\mathbf{y}(t)\), each output variable applies its rule \(h_j\) to the current internal state \(\mathbf{u}(t)\).

Basically, the state trajectory of the system depends on the starting state as well as the inputs entering over time. About now is a good time for a simple example.

Example 2.1: Consider a synchronous boolean control network with \(n = 2\) state variables (\(V = \{v_1, v_2\}\)), \(m = 1\) input variable (\(U = \{u_1\}\)), and \(p = 1\) output variable (\(Y = \{y_1\}\)). The global transition function \(F(\mathbf{x}(t), \mathbf{u}(t))\) and global output function \(H = (\mathbf{x}(t))\) are: \[ F(\mathbf{x}(t), \mathbf{u}(t)) = \begin{pmatrix} f_1(\mathbf{x}(t), \mathbf{u}(t))\\ f_2(\mathbf{x}(t), \mathbf{u}(t)) \end{pmatrix} = \begin{pmatrix} x_2(t) \land \neg u_1(t)\\ x_1(t) \lor u_1(t) \end{pmatrix} , \quad H(\mathbf{x}(t)) = h_1(\mathbf{x}(t)) = x_1(t) \oplus x_2(t) \] Because \(m = 1\), the input space contains \(2^1 = 2\) possible input vectors, \(\mathbf{u}^{(0)} = (0)\) and \(\mathbf{u}^{(1)} = (1)\). Finite State Machines and Moore Machines

And now we jump away to what seems like quite a different topic. Automata are abstract models of computing devices that move through states based on inputs.3 These inlcude, in order of decreasing computational power, Turing machines, linear-bounded automata, pushdown automata, and finite state machines. Within finite state machines, we can further narrow our focus to machines that are deterministic transducers. This means their rules are predefined and not random, and that they produce output for each time step of operation, as opposed to acceptors, which only produce one output at the end of operation. There are two kinds of these determinisic transducers:

3 I really do like the word automata (plural), or automaton (singular). Its comes from the Ancient Greek word αὐτόματον, meaning “acting of one’s own will” or “self-moving”.

  • Moore Machine: The output depends only on the current state.
  • Mealy Machine: The output depends on both the current state and current input.

Our business today is with Moore machines. Formally, a Moore machine is a tuple \(M = (Q, \Sigma, \Gamma, \delta, \lambda, q_0)\), where the components are defined as follows:

  • \(Q\) is a non-empty finite set of states.
  • \(\Sigma\) is a non-empty finite set representing the input alphabet.
  • \(\Gamma\) is a non-empty finite set representing the output alphabet.
  • \(\delta: Q \times \Sigma \rightarrow Q\) is the state transition function, mapping a state \(q \in Q\) and an input symbol \(a \in \Sigma\) to a next state \(\delta(q, a) \in Q\).
  • \(\lambda: Q \rightarrow \Gamma\) is the state output function, mapping a state \(q \in Q\) to an output symbol \(\lambda(q) \in \Gamma\).
  • \(q_0 \in Q\) is the initial state.

Synchronous Boolean Control Networks, Moore Machines, Agents, and Environments

It is possible to view a synchronous Boolean control network as a concrete instantiation or realization of a Moore machine, where:

  • The state space is \(Q = \{0, 1\}^n\).
  • The input alphabet is \(\Sigma = \{0, 1\}^m\).
  • The output alphabet is \(\Gamma = \{0, 1\}^p\).
  • The state transition function \(\delta\) is the global state transition function \(F: \{0, 1\}^n \times \{0,1\}^m \rightarrow \{0, 1\}^n\).
  • The state output function \(\lambda\) is the global output function \(H: \{0, 1\}^n \rightarrow \{0, 1\}^p\).
  • The initial state is \(\mathbf{x}(0)\), whatever that may be.

This connection allows us to introduce ideas from dynamical systems, such as fixed point and limit cycle attractors and basins of attraction, into the study of finite state computation.

Standard finite state machines are computationally limited because of their finite state spaces. To achieve more powerful models of computation, let us imagine Moore machines as agents in environments. If the environment has even some degree of persistence and the agent has outputs that can modify this environment, then more complex computation may be possible.

An interesting thought is that people themselves are finite and do not remember everything. Instead they use their external environment to store and access information to perform complex computation.
