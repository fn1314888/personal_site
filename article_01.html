Introduction

Synchronous Boolean networks are basically collections of ON/OFF switches that update their state at the same time. It may sound simple, but they can exhibit dynamics, patterns, and properties that can’t be understood from looking at the individual parts alone. We will first ground our approach of the topic in dynamical systems.

Dynamical Systems

A dynamical system is a tuple \((T, X, \Phi)\), where the components are defined as follows:

  • \((T, +)\) is a commutative monoid representing time.
  • \(X\) is a non-empty set representing the state space.
  • \(\Phi : T \times X \rightarrow X\) is a function that maps a time duration \(\tau \in T\) and a state \(\mathbf{x} \in X\) to a new state \(\Phi(\tau, \mathbf{x}) \in X\) such that the following two axioms are satisfied for all \(\mathbf{x} \in X\) and \(\tau_1,\tau_2 \in T\):
    1. Identity: \(\Phi(0, \mathbf{x}) = \mathbf{x}\)
    2. Semigroup Property: \(\Phi(\tau_2, \Phi(\tau_1, \mathbf{x})) = \Phi(\tau_1 + \tau_2, \mathbf{x})\)
NoteIn Plain English

A dynamical system describes a process that updates over time according to a fixed, deterministic rule. It has three parts:

Time (\(T\)): There is a time duration that acts like \(0\), and time can be added together.

State Space (\(X\)): This is a non-empty set of every state the system could ever possibly be in.

Transition Rule (\(\Phi\)): A function that takes a current state \(\mathbf{x}\) and a time duration \(\tau\), returning the state of the system after \(\tau\) units of time. The axioms mean:

  1. If zero time passes, the system remains unchanged.
  2. The flow of time is consistent. Evolving a state forward by \(\tau_1\) time units then by \(\tau_2\) time units gives the same result as evolving it forward by \(\tau_1 + \tau_2\) time units in a single jump.

Now we will introduce synchronous boolean networks as dynamical systems with discrete time and finite, discrete state space.

Synchronous Boolean Networks

A synchronous Boolean network is a tuple \((V, F)\), where the components are defined as follows:

  • \(V\) is a finite ordered set of \(n\) variables \(V = \{v_1, v_2, \dots, v_n\}\), where each variable takes values in \(\{0, 1\}\). At time \(t \in \mathbb{N}_0\), the state vector \(\mathbf{x}(t) = (x_1(t), x_2(t), \dots, x_n(t)) \in \{0, 1\}^n\) assigns a value \(x_i(t) \in \{0, 1\}\) to variable \(v_i\) at time \(t\).
  • \(F: \{0, 1\}^n \rightarrow \{0, 1\}^n\) is a global state transition function defined by \[ F(\mathbf{x}(t)) = (f_1(\mathbf{x}(t)), f_2(\mathbf{x}(t)), \dots, f_n(\mathbf{x}(t))) \] where each local function \(f_i: \{0, 1\}^n \rightarrow \{0, 1\}\) governs the next state value \(x_i(t + 1)\) of variable \(v_i\).

The state of the system evolves over time according to the discrete update rule: \[ \mathbf{x}(t + 1) = F(\mathbf{x}(t)) \]

In the context of dynamical systems, a synchronous Boolean network instantiates \((T, X, \Phi)\) as follows:

  • \(T = \mathbb{N}_0 = \{0, 1, 2, \dots\}\).
  • \(X = \{0, 1\}^n\).
  • \(\Phi: \mathbb{N}_0 \times \{0, 1\}^n \rightarrow \{0, 1\}^n\) maps a state \(\mathbf{x}(t)\) and time duration \(\tau\) to state \(\mathbf{x}(t + \tau)\): \[ \Phi(\tau, \mathbf{x}(t)) = \mathbf{x}(t + \tau) = F^\tau(\mathbf{x}(t)) \] where \(F^0(\mathbf{x}(t)) = \mathbf{x}(t)\), and \(\mathbf{x}(t + 1) = F(\mathbf{x}(t))\) for all \(t \in \mathbb{N}_0\).
NoteIn Plain English

A synchronous Boolean network models a system of interconnected ON/OFF switches that all update at the same time. It has two parts:

  • Variables (\(V\)): This is a list of \(n\) switches. At any time, each switch is either \(0\) (OFF) or \(1\) (ON). A state \(\mathbf{x}(t)\) is a snapshot showing the ON/OFF status of every switch at some point in time \(t\).

  • Global Function (\(F\)): This is a master update rule made of \(n\) individual rules, one for each switch. Each time step, every switch looks at the current snapshot \(\mathbf{x}(t)\), and updates according to its rule \(x_i(t + 1) = f_i(\mathbf{x}(t))\). All switches update at the same time to yield the next state \(\mathbf{x}(t + 1)\).

A synchronous Boolean network maps to a dynamical system as follows:

  • Time (\(T\)): Time starts at \(0\), and continues step by step \((0, 1, 2, \dots)\).
  • State Space (\(X\)): This is the set of all \(2^n\) possible ON/OFF combinations of the \(n\) switches.
  • Transition Rule (\(\Phi\)): Given an initial state \(\mathbf{x}(t)\), to find the system’s state \(\mathbf{x}(t + \tau)\) after \(\tau\) steps, apply the global function \(F\) repeatedly \(\tau\) times \((F^\tau(\mathbf{x}(t)))\). Applying it zero times \(F^0(\mathbf{x}(t))\) leaves the state unchanged.

By now, we have developed a sense that the term synchronous describes variables updating all at the same time, and the term Boolean1 describes how each variable exists in an ON or OFF state at each point in time. Now we will give more meaning to the final term network.

1 Named after mathematician George Boole, whose work on Boolean algebra bridged mathematics and philosophy, and laid the foundations for wonderful things like computer science and digital electronics.

Interaction Graphs

The interaction graph of a synchronous Boolean network is a directed graph \(G_I = (V, E_I)\) that represents the dependencies between variables, where the components are defined as follows:

  • \(V = \{v_1, v_2, \dots, v_n\}\) is the set of vertices, corresponding to the set of variables in the network.
  • \(E_I \subseteq V \times V\) is the set of directed edges, where the directed edge \((v_j, v_i) \in E_I\) exists if and only if there exists a state \(\mathbf{x}(t)\) such that changing \(x_j(t)\) alters \(f_i(\mathbf{x}(t))\).
NoteIn Plain English

An interaction graph of a synchronous Boolean network shows which variables depend on which variables. The graph is made of:

  • Vertices(\(V\)): Each switch (variable \(v_i\)) is a vertex.
  • Edges(\(E_I\)): An arrow from \(v_j\) to \(v_i\) means that \(v_j\) affects the outcome of \(v_i\)’s update rule \(f_i\).

While the global function \(F\) defines how the state of every variable changes, the interaction graph \(G_I\) provides a more visual understanding of which variables affect each other.2

2 Presenting the network as a graph also allows for techniques from graph theory and network science to be applied to the analysis of synchronous Boolean networks, which is quite nice.

This example considers the evolution of a synchronous Boolean network starting from one specific initial state, but what if we were bold enough to imagine all possible evolutions from all possible starting states? This naturally leads to the idea of state transition graphs.

State Transition Graphs

The state transition graph of a synchronous Boolean network is a directed graph \(G_{ST} = (X, E_{ST})\) that represents the state space dynamics, where the components are defined as follows:

  • \(X = \{0, 1\}^n\) is the set of vertices, representing all possible state vectors \(\mathbf{x}(t)\) of the network.
  • \(E_{ST} \subseteq X \times X\) is the set of directed edges, where a directed edge \((\mathbf{x}, \mathbf{y}) \in E_{ST}\) exists if and only if \(\mathbf{y} = F(\mathbf{x})\).
NoteIn Plain English

A state transition graph of a synchronous Boolean network maps out every single possible path the network can take over time. The graph is made of:

  • Vertices(\(X\)): Each of the \(2^n\) possible combinations of \(n\) ON/OFF switches is a vertex.
  • Edges(\(E_{ST}\)): An arrow from state \(\mathbf{x}\) to state \(\mathbf{y}\) means that applying the global function \(F\) on state \(\mathbf{x}\) directly yields state \(\mathbf{y}\) in the next time step.

It is worth noting that the number of vertices in the state transition graph \(G_{ST}\) grows exponentially with the number of variables \(n\), since \(X =\{0, 1\}^n\) contains \(2^n\) distinct states. Constructing, storing, or analyzing the full state transition graph with brute force has \(\mathcal{O}(2^n)\) time and space complexity. Attractors

An attractor \(A \subseteq X\) of a synchronous Boolean network is a non-empty set of state vectors that forms a directed cycle in the state transition graph \(G_{ST}\). \(A = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_k\}\) is an attractor of period \(k \in \mathbb{N}\) if:

  1. \(F(\mathbf{x}_i) = \mathbf{x}_{i + 1}\) for all \(1 \leq i < k\), and \(F(\mathbf{x}_k) = \mathbf{x}_1\).
  2. For every \(\mathbf{x} \in A\), the trajectory initialized at \(\mathbf{x}\) satisfies \(\Phi(\tau, \mathbf{x}) \in A\) for all \(\tau \in \mathbb{N}_0\).

Because the state space \(X = \{0, 1\}^n\) is finite (\(|X| = 2^n\)) and the global function \(F\) is deterministic, every initial state \(\mathbf{x}(0)\) eventually reaches an attractor in at most \(2^n - 1\) time steps.

By the Pigeonhole Principle, any sequence of \(2^n + 1\) states \(\mathbf{x}(0), \mathbf{x}(1), \dots, \mathbf{x}(2^n)\) must contain at least one repeated state, guaranteeing that the trajectory enters an attractor.

NoteIn Plain English

An attractor is a state or loop of states that the system gets trapped in forever once it enters.

Because there are only \(2^n\) states, and because each state has exactly one arrow pointing to its next state, any path longer than \(2^n\) that you take through the state transition graph must eventually loop back to a state already visited, and then you are permanently inside the attractor. These loops are the long-term stable behaviours of the network.

TipOptional

Theorem 1.1: Every synchronous Boolean network \((V, F)\) has at least one attractor, which is reached by any state trajectory \(\mathbf{x}(0), \mathbf{x}(1), \mathbf{x}(2), \dots\) in at most \(2^n - 1\) steps.

Proof: Let \(\mathbf{x}(0) \in X = \{0, 1\}^n\) be an arbitrary initial state. Consider the sequence of \(2^n + 1\) states generated by repeatedly applying the deterministic global function \(F\): \[ \mathbf{x}(0), \mathbf{x}(1), \dots, \mathbf{x}(2^n) \] where \(\mathbf{x}(t) = F^t(\mathbf{x}(0))\).

Since the state space contains exactly \(|X| = 2^n\) distinct states, by the Pigeonhole Principle, a sequence of length \(2^n + 1\) must contain at least one repeated state. So there exist two time indices \(t_1, t_2 \in \mathbb{N}_0\) with \(0 \leq t_1 < t_2 \leq 2^n\) such that: \[ \mathbf{x}(t_1) = \mathbf{x}(t_2) \] Because \(F\) is a deterministic function, for all steps \(k \geq 0\): \[ \mathbf{x}(t_1 + k) = \mathbf{x}(t_2 + k) \] Setting \(k = t_2 - t_1\) shows that the state trajectory forms a closed cycle \(A = \{\mathbf{x}(t_1), \mathbf{x}(t_1 + 1), \dots, \mathbf{x}(t_2 - 1)\}\) of period \(t_2 - t_1\). Thus, the sequence enters an attractor \(A\) after at most \(t_1 \leq 2^n - 1\) steps.\(\blacksquare\)

Depending on the period \(k\) of the cycle, attractors in synchronous Boolean networks are of two types:

  • Fixed Point: The period is \(k = 1\), so the attractor \(A = \{\mathbf{x}^*\}\) contains a single state such that \(F(\mathbf{x}^*) = \mathbf{x}^*\).
  • Limit Cycle: The period is \(k > 1\), so the attractor has multiple distinct states \(A = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_k\}\) that are visited in sequence repeatedly.

Every attractor \(A\) influences some part of the state space \(X\). The basin of attraction \(B(A) \subseteq X\) associated with an attractor \(A\) is the set of all initial states whose trajectories eventually enter \(A\): \[ B(A) = \{\mathbf{x} \in X \mid \exists \tau \in \mathbb{N}_0, \Phi(\tau, \mathbf{x}) \in A\} \] The basins of attraction form a partition of the state space \(X\). Once again, it is worth pointing out that finding all attractors of a synchronous Boolean network has \(\mathcal{O}(2^n)\) time and space complexity.3 Let us now revisit Example 1.2 to see all of these concepts in play.

Conclusion

We started with dynamical systems, and in that context we introduced synchronous Boolean networks. Then we covered different ways to view them, through interaction graphs and state transition graphs. Then these views lead to the concept of attractors.
